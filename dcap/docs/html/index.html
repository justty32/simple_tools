dcap C/C++ scaffolder

極簡的 POSIX/UNIX（以 Linux 為主）CLI 工具：把模板複製成新專案、替換 @NAME@、並 git init。

總覽 使用指南 設計說明

一分鐘上手

make                       # 建置 dcap → bin/dcap，然後自行把 bin/ 加入 PATH
dcap cpp hello             # 用內建 cpp 模板建立 ./hello（並 git init）
cd hello && make run       # → 2 + 3 = 5

唯一指令

dcap <template> <name>

<template> = 模板來源；<name> = 要建立的新專案目錄。行為：把模板原樣複製成 ./<name>/、只在 Makefile/makefile 內替換 @NAME@、git init。沒有子指令、沒有 help；參數不足時印 usage 到 stderr 並回傳 1。

模板三種來源

來源說明
路徑式<template> 開頭是 . 或 /（./x、../x、/abs/y）→ 相對 cwd 或絕對路徑；a/b 這種不以 .// 開頭的當裸名
具名外部設了 DCAP_TEMPLATES 時，裸名先去 $DCAP_TEMPLATES/<名> 找；同名時蓋過內建 c/cpp
內建c（gcc -std=c11 -lm -lpthread）/ cpp（g++ -std=c++20），以 #embed 編進執行檔，永遠可用

合法模板 = 該目錄底下有 Makefile 或 makefile。解析順序即上表由上而下。

特點

定位POSIX-only（以 Linux 為主），已放棄跨平台
只依賴gcc/g++ + git + make（不用 CMake；make fmt 另需 clang-format）
內建模板即真檔範本存於 templates/，以 C++20 #embed 編譯期嵌入
產生的專案單一產物 main：既能 ./main 執行，也能被 -l<name> 連結或 dlopen
佈局include/ 公開標頭、src/ 全部原始碼（無命名規則）、test/ 測試
include-Iinclude（已移除 DCAP_HOME）；C 模板連結 -lm -lpthread
