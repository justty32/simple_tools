# AOS 實驗工作區

地位：暫存，不是正式規格。完成的結論由主 agent 重寫後才可進入正式文件。

## 寫入規則

1. 每個原型只有一位寫入者，目錄為 `<回合>/<角色>/`。
2. 子 agent 不修改根目錄、`full/`、`archived/` 或別人的目錄。
3. 交叉評審只讀；修正意見交給原作者或主 agent。
4. 原型必須附 `README.md`，寫清假設、執行方式、結果與使用感受。
5. 主 agent 驗證後才抽取共同部分；不直接複製實驗稿成正式規格。
6. 淘汰但有價值的實驗移入 `archived/`；無追溯價值的產物在確認後清理。

## 單一擁有者

- 主 agent 負責裁決，不和文檔員同時修改正式稿。
- 一位 Sol 文檔員持有 `full/` 或指定的根層 Markdown；交棒前其他人只讀。
- Terra 原型員各自只持有一個 prototype 目錄。
- Luna 驗證員預設只讀；驗證報告寫進自己的目錄。
- HTML 編輯者只持有指定 HTML／CSS，不改 Markdown。
- 使用者的新意見先形成修訂單；主 agent 裁決後，批次交給檔案擁有者。

## 預定回合

- `round-1/`：最小 Function、Step 與檔案記憶體。
- `round-2/`：Task、queue、manager 與恢復。
- `round-3/`：`.aos/` 體驗與最小 agent 擴充。
