網路與 SSE 解析坑點

TCP 斷碎緩衝 (Line Buffering)：libcurl 每次回傳的片段不保證以 \n 結尾，必須自建字串 Buffer 拼接至完整行後才能送入 json::parse，避免 JSON 解析崩潰。

HTTP 狀態碼攔截：非 200 回應（如 429 Rate Limit、500 Server Error）回傳的是一般 JSON 而非 SSE 串流，需先判定 Status Code 避開 SSE 處理邏輯。

指數退避重試：對 429/5xx 錯誤加入 max_retries 與指數退避機制，強化 API 連線容錯率。

2. 串流與進階模型能力解構

併發 Tool Calls 組合：多工具同時調用時，JSON 引數片段會隨 delta.tool_calls[i].index 交錯傳入，必須維護以 index 為 Key 的映射表（Map）分別拼湊完整 JSON。

推理思考鏈 (Reasoning)：原生解析 DeepSeek-R1 的 <think> 標籤與 delta.reasoning_content 欄位，分流至思考專用的 Handler。

流式中斷 (Abort)：Async 模式需提供 Controller，透過 libcurl 的 Progress Callback 回傳非零值強制在中途切斷連線。

Token 統計與 Debug：擷取 SSE 結尾的 usage 數據，並留有 on_raw_chunk 鉤子方便除錯。

3. C++ 記憶體與多執行緒安全

Shared Pointer 生命週期防護：背景 std::thread 執行時，若外部呼叫端作用域結束，容易引發懸空指標 (Dangling Pointer) 或 Use-After-Free 崩潰。所有 Handler 與 Controller 必須以 std::shared_ptr 綁定生命週期。

非阻塞異步：底層包裝 std::thread，發送請求時不卡死主執行緒或 UI 介面。

4. 實用的輔助封裝

對話歷史 (ChatSession)：自動將 System/User/Assistant 及 Tool 回傳結果追加進 messages 陣列，簡化多輪對話維護。

Vision 圖片轉換器：提供本地圖片檔案直接編碼為 Base64 Data URI 的 Helper 函式。
