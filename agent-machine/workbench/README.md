## 如何使用工作台

1. 把 Python 視為**可執行參考模型**：能跑、能製造反例、能和 C++ 差分比對；不要照抄其模組架構。
2. 原型通過只證明 README 明列的作業系統、檔案系統與故障模型。
3. 工作台的 JSON、ID、目錄與事件名稱都是實驗格式；提升為正式介面前仍要裁決。
4. C++ 每次只取代一個責任，並重跑相同 fixtures；不同結果要先解釋，不能以「語意差不多」帶過。
5. 單檔不得超過 8192 bytes；超過時依責任拆檔。
