dcap C/C++ scaffolding & build

輕量、跨平台（Windows/MinGW + UNIX）的 CLI 工具，快速建立與建置純 C 或 C++ 的腳本式小專案。

總覽 使用指南 設計說明

一分鐘上手

make                 # 建置 dcap（Windows 用 mingw32-make）
dcap new hello       # 建立 C++ 小專案 + git init
cd hello
dcap build           # 編譯並執行 → Hello, World! (C++)

指令

指令作用
dcap new <name>建立 C++ 專案（g++ -std=c++20）
dcap new-c <name>建立 C 專案（gcc -std=c11 -lm -lpthread）
dcap buildmake -j4 後執行 bin/ 內的產物
dcap help顯示說明

特點

只依賴gcc/g++ + git + make（不用 CMake）
跨平台保留 UNIX 慣例字串，執行期 #ifdef _WIN32 + std::filesystem 偵測
模板即真檔範本存於 templates/，以 C++20 #embed 編譯期嵌入
可攜產物dcap 與產生的專案皆 -static 靜態連結
共用 lib環境變數 DCAP_HOME（預設 ~/dev/dcap、C:/dev/dcap）
