使用指南

安裝、指令、DCAP_HOME 與疑難排解。

總覽 使用指南 設計說明

安裝

# UNIX / macOS
make
sudo ./install.sh            # 複製 bin/dcap → /usr/local/bin
#   ./install.sh ~/bin       # 或指定其他目錄

# Windows (MinGW)
mingw32-make                 # 產出 bin\dcap.exe

Windows 上把 bin 加入 PATH，或把 dcap.exe 複製到已在 PATH 的目錄。

指令

dcap new <name> — C++ 專案

建立 <name>/，含 Makefile、main.cpp、.gitignore，並執行 git init。Makefile 使用 g++ -std=c++20、-I. -I$(DCAP_HOME)/cpp_libs、find 遞迴搜尋、靜態連結、輸出 bin/<name>。

dcap new-c <name> — C 專案

同上，改用 gcc -std=c11、-I$(DCAP_HOME)/c_libs、連結 -lm -lpthread、搜尋 .c、範本 main.c。

dcap build — 建置並執行

檢查有 Makefile（無則報錯）；執行 make -j4（Windows：mingw32-make -j4）；成功後於 bin/ 找產物並執行，印出退出碼。

DCAP_HOME：共用函式庫根目錄

平台預設
UNIX / macOS~/dev/dcap
WindowsC:/dev/dcap

覆蓋：DCAP_HOME=/opt/libs dcap build 或 make DCAP_HOME=/opt/libs。把共用標頭放進 cpp_libs/ 或 c_libs/ 即可直接 #include。目錄不存在也無妨。

疑難排解

症狀原因 / 解法
dcap.exe 一啟動就退出、無輸出非 -static 版缺 MinGW DLL；用本專案 Makefile 重建即為靜態。
Windows 上 find 錯誤或找不到原始碼mingw32-make 用到 cmd.exe。在 Git Bash 執行，或把 C:\Program Files\Git\usr\bin 放到 PATH 前段。
找不到 make確認 make（UNIX）或 mingw32-make（Windows）在 PATH。
想換編譯器make CXX=clang++ 或 make CC=clang；明確指定會覆蓋預設。
