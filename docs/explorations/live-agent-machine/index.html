RESEARCH MAP · 2026-08-11

讓 agent 在持續變動的世界中，仍能可靠地求值

這份導覽連接報告的八個章節：從 workspace form 與版本邊界，走到 evidence、人工介入與未來的 Image Workbench。

◉ Agent Machine 是一台對 versioned world form 持續求值的慢速機率 machine；每次改動先經 typed intent、generation check 與 settlement，才成為下一次可見的新定義。

THREE CONSEQUENCES

命題帶來的三項洞見

01

程式是 live world

prompt 是入口；workspace、namespace、capability、memory 與 goal 才構成 closure。

02

資源也是 assurance

token、成本、證據與人類注意力需要一起調度，且不能被壓成一個信心分數。

03

編輯器需要多種 lens

除了檔案，還要能追問時間、因果、context、effect、權限與證據。

EVALUATION FLOW

一個可提交的 world transition

  1. 編輯 world formsource · mount · tool · memory · goal
  2. 編譯固定 viewversioned image → Step manifest
  3. 提出並驗證 intentproposal → capability / policy / verifier
  4. settle 成新 generationcommit · evidence · replayable event

全程橫跨：cost ledger、assurance graph、human intervention network。
