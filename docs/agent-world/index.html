Agent World

把 agent 理解成在私有 namespace 中求值的 process；把記憶理解成可掛載、可追溯的結構；把每一輪模型輸入理解成由 manifest 編譯出的有限 working set。

path/namespace → agent/team → memory graph → Step context
　　　handle/capability ↘ Round activity ↘ tick/world transition

建議閱讀路線

START

總覽與核心命題

三層架構、八個新觀點，以及這套設計是不是 container based。

 01 · SUBSTRATE

歸一於路徑

canonical identity、per-agent view、path/object/handle、快慢世界與 unipath 實證。

 02 · CONTRACT

九軸契約

概念軸與 metadata fields 的差異；declared/effective/observed；組合推導。

 03 · COGNITION

組織化記憶

trace、objects、fact graph、grounding、LOD 與每輪 context manifest。

 04 · TIME

Step、Round、tick

模型、單一 agent、多 agent 世界各自的時間尺度，以及工具內互動。

 05 · ENFORCEMENT

協定與隔離

data/status/ctl、clone transaction、fd capability、secret broker 與 sandbox 邊界。

 06 · BUILD

分期路線

從純資料契約、read-only resolver、memory manifest，一路到 9P 與 runtime sandbox。

 EVIDENCE

來源與可信度

區分 ai_core 正式規範、handy 未定案思考、unipath 原型實證與本報告推論。

一句話關係

namespace 決定 agent 看見的世界；handle 承載已解析的能力；九軸描述節點的執行性質；memory graph 保存證據與推論；context compiler 為每個 Step 選出 working set；Round 管單一 agent 的活動；tick 才協調多個主體共同改變世界。
