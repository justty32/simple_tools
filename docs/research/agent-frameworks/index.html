Swarm、Instructor、MiniChain、PocketFlow、LightAgent、LangGraph、CrewAI 的 source-level 比較，以及它們如何接到 freepy 的 Round／Step、agent path、memory、runtime 與 agentfs。

schema → model attempt / Round
intent → policy → approval → sandbox effect → receipt
