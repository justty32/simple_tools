PATH · VIEW · HANDLE · EVENT

Agent World 是一套 logical runtime，不是一棵神奇目錄

若你熟悉 Unix、Go service 或韌體控制面，可把它看成：為每個 agent 組一個私有、可稽核的 service namespace；模型只在有限 working set 中提出動作，supervisor 才提交真正狀態與副作用。

一次操作穿過五個不同責任

/tools/search 只像 symbol 或 service name；open 後的 handle 才像綁定 principal、generation 與 rights 的 fd。provider 是資料真源，agentfs 只是 projection；Linux namespace/cgroup/seccomp 才是實體 enforcement。

六個常被壓成同一件事的概念

Agent identity

穩定的 canonical path，例如 /root/build/tests；回答「我是誰」，不自帶全域可見性。

Private view

/self、/tools、/memory 是 supervisor 為當次 actor/session 組出的 environment。

Object / instance

memory hash 或 live instance 指向特定版本；重啟後可換 incarnation，同一路徑不代表同一實體。

Handle / fid

類似 fd 加 capability token。舊 generation 被撤回後必須 stale，不能偷偷解析到同名新 instance。

Status / events

status 像 materialized view；events 像 append-only journal。前者答現在，後者答怎麼走到現在。

Declared / effective / observed

需求宣告、實際授予、runtime 量測三者分開；requested network 絕不能冒充已獲授權。

三種時鐘，不要共用一個 step counter

尺度工程邊界具體例子
Step一次 provider ask → message一次 ADC sample/計算量子；tool 在兩個 Step 之間執行
Round單一 agent 由指令啟動到主動停止一次 transaction attempt；可含多個 Step、tool 與追加指令
tick多 actor/world 的同步與 commit 邊界控制迴圈的一拍；可收集多個 Round、script 與 intervention

重播 Step 只固定 model input；重播 Round 還要固定 tool/environment；重播 tick 還要固定 schedule、介入與世界狀態。三者不是別名。

compact 不是刪 history，而是重新編譯 view。card、summary、section、full 都是同一 object 的載入層級；AI 猜測先是 hypothesis，經 review 成 accepted grounding 後才可當確定性前提。

類比的失效點

路徑不是權限、projection 不是資料庫、namespace 不是 sandbox、container 也不是 Agent World 本身。任何 control write 都要轉成 typed operation，重新檢查 actor、scope、instance、generation 與 idempotency；沒有 OS enforcement 時不得回報「已隔離」。
