Scheduler simulation

規模

10,000 dormant Functions、數百 queued Rounds、固定 K slots；thread 與 active memory 有界。

公平

兩個 owner 長短工作混合都不飢餓；長 prompt 不因估算誤差永遠排不到。

壓力

429/5xx 在 pool 共享 backoff + jitter，不產生 retry herd。

Live smoke 的清理規則

Ollama 測試預設 4096 output tokens／Step、12 Steps、8 calls、900 秒。切模前確認其他 lease；測完在 finally unload 最後模型並檢查 residency。

預設只保存 redacted manifest hash、model revision、usage 與 cleanup 結果。Raw prompt、system message、tool output 必須明確 opt in。

Python reference 何時算完成

  • 重啟後 queue、Round、generation、usage 與檔案可恢復。
  • 含 LLM + tools 的 Round 能在 safe boundary pause/resume；replay 不重呼模型或工具。
  • 多 Round 共享 endpoint 不超賣、不餓死；late/duplicate result 不提交。
  • Git 能 branch、diff、promote；active ref 可 CAS 回舊 revision。
  • GC 預設 archive-first；刪除前重驗 generation、pin 與 lease。

Native 何時能成為 default

  • Python/C++ corpus 在約定欄位 100% 一致，差異有版本化說明。
  • C++ 是唯一 commit authority；Janet 拔掉、報錯或 process timeout 仍保持安全。
  • Linux clean build、sanitizer、fuzz、crash recovery、真 executor smoke 長期維持綠。
  • 從空 workspace 能 init、run、inspect、recover、switch model、GC、rollback。
