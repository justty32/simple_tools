PLAIN-LANGUAGE GLOSSARY

名詞很多，層次其實不多

先看已完成的本地 core，再看正在起步的外圍 Agent Machine。後者不會改變 Controller 的日常用法。

目前本地 core

Round

一個 agent 從開始到停止的一整段工作。

可以包含很多 Step 與 tools；模型沒叫工具不一定等於 Goal 達成。

Step

一次 ask() → message。

工具發生在兩個 Step 之間，不另算模型 Step。

safe boundary

Step 或整批 tools 完成後，可以合作式停下的位置。

「safe」只表示不切半個 operation，不表示工具本身安全。

Handle

同 process 內直接抓住一個 Round 的公開把手。

可讀寫狀態、pause/resume/end；能力大，正確性由操作者負責。

Controller

組合 Handle 與 runner 樣板的本地方便 wrapper。

不是 durable control plane，也不是 security boundary。

runner

真的呼叫 model 與 tools 的執行 thread。

一個 Handle 只有一個 owner runner；observer/controller threads 可另外存在。

worker

未來 runtime 裡可承接工作的 process 或 machine。

比 runner 更外圍；可能被換掉、租用或重啟。

Limits

在 callback boundary 檢查步數、工具、時間與 token 的 policy。

合作式限制，不是 CPU/RAM/network sandbox。

Agent Machine 規劃用語

command / event

command 是請求；event 是已接受並記下的事實。

請求可拒絕，event 用來重建狀態。

revision / generation

防止舊回報覆蓋新狀態的版本號。

只表示觀察的版本，不等於權限。

transaction

一組資料更新全成功或全不算。

例如同時記下結果並排下一件工作，避免只完成一半。

store / snapshot

store 保存真源；snapshot 是加速讀取的快照。

snapshot 壞掉應能由可信 events 或 records 重建。

queue / scheduler

queue 放待辦；scheduler 決定誰何時取得資源。

單一 Handle 不需要它們；大量工作才需要公平、backoff 與容量。

lease

worker 暫時取得某件工作的執行權。

過期後的結果不能直接覆蓋新 generation。

Candidate

模型提出的候選答案或完成宣稱。

不是完成事實；要由 evidence/verifier 或使用者決定。

Goal / evidence / verifier

Goal 定條件；evidence 留證據；verifier 判斷是否達標。

另一個模型的評語仍是機率證據，不自動等於真相。

ledger / resource

帳本追蹤 token、錢、endpoint slot、context 等有限資源。

資源 accounting 與 OS sandbox 是兩回事。

unknown effect

外部動作可能已成功，但結果在 crash 時遺失。

需查證或人工處理；不能把寄信、付款等盲目 retry。
