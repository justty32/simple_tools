C++23 CORE · JANET POLICY

只有 C++ 能提交；Janet 只能選

Python 契約穩定後再固化。C++ 掌握不能破壞的 mechanics；Janet 從核心給的合法候選中選 policy，不拿到 I/O、secret 或 commit pointer。

慢 I/O 全在 worker pool。UI、timer、network completion 不能直接鎖住並修改大 object graph。量測證明單 commit loop 是瓶頸前，不做 sharding。

Value semantics 不等於深拷貝：實作可用 immutable blocks 與 structural sharing；跨 ABI 和 journal 才使用 canonical bytes。

Janet 的硬邊界

Owner thread

Process startup 只 init runtime 一次。Policy env 只由 owner thread 進入；reload 建新 process/env，不共享 mutable table。

不能安全 kill thread

Embedded Janet 只跑受信、工作量有界的 policy。需要硬 deadline 或不受信 code，就放受限 process，timeout kill whole process。

沒有 raw C++ pointer

Opaque value 只存 handle id、generation、capability；owner thread 查 registry，再短暫取得物件。

沒有跨 call Janet root

C++ core 不保存 Janet、buffer 或 table pointer；跨界資料一律 copy／serialize。

最容易踩到的 C／C++ 邊界

Janet non-local error 不能穿越 C++ RAII frame。 可能報 Janet error 的 janet_get*／janet_fixarity 放在窄 C shim；先解成 owned POD，再進捕捉所有 exception 的 C++ implementation。Lock、transaction、owning pointer 都不能橫跨這條邊界。

C ABI 只在真的需要時提供

typedef struct am_core am_core;
typedef struct { uint32_t abi; const uint8_t *data; size_t size; } am_view;
typedef struct { uint8_t *data; size_t size; } am_owned;

int am_step(am_core *, am_view, am_owned *out, am_owned *error);
void am_owned_free(am_core *, am_owned *);

STL、exception、allocator 不跨 ABI。Buffer 由同一 library/version 釋放；另定 calling convention、visibility、reentrancy 與 destroy 等待 in-flight call 歸零。跨 process 優先 framed stdio，少背一個 cross-CRT allocator 問題。

Python sidecar 不是隨便印 JSON

  • Length-prefixed、versioned frame；stdout 只跑 protocol，stderr 才是 log。
  • 帶 request、instruction、attempt id、deadline、payload hash 和大小上限。
  • Dispatch 後 EOF 是 outcome_unknown，不能普通 retry。
  • Secret 經 restricted FD／OS store 傳入，不寫入 journal。

Build 與固化順序

  1. 凍結 Python corpusJSON vectors、journal traces、crash points。
  2. C++ shadow CLI同輸入逐欄 diff；先不接真 LLM。
  3. C++ 接手 mechanicsPath、transaction、replay、ledger、scheduler。
  4. Janet shadow policy每個差異分成 spec、bug 或 versioned policy change。
  5. Linux production gatesCMake clean build、GCC/Clang、ASan/UBSan/TSan、fuzz。

Janet 固定版本並靜態連入；bundle 記 runtime version、target、source/module hash 與 policy schema。Hash 保證完整性，不代表 sandbox 信任。
