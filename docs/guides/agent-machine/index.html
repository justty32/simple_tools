先造一台不會忘記事情的機器

Agent Machine 不取代作業系統。它把 Function、模型、工具與狀態放進同一個可尋址空間，讓每次修改都能驗證、恢復與追蹤。

從第一個 PR 開始閱讀正式規格

語言分工

Python 先把規則跑通並產生測試向量。

C++23 最終掌握提交、儲存、排程與 OS 邊界。

Janet 表達可替換 policy，不直接做 I/O 或提交狀態。

現在：pure namespace contract下一站：directory journal + crash recovery限制：單檔 < 8 KB

THE MACHINE

一條資料主線，兩種執行者

shell / API提出 operation
→
machine core驗證 + 發布 generation
→
executorLLM / tool / file / Git
→
result證據，不直接改真源

唯一提交者：只有 machine core 能發布新的 VFS root generation。Worker 再快、模型再有自信，都只能回傳結果。

Derived view

幾個已經拍板的決定

外觀是檔案

使用者用 path、read/write 與普通 shell；控制 write 在內部轉成有型別、帶版本的 operation。

Path 不是身分

Rename 只改名稱；node_id 才是永久身分，handle 還綁 snapshot、actor 與權限版本。

Git 不是真源

VFS HEAD 是目前狀態；journal 負責恢復；Git 負責人看得懂的 branch、diff 與 checkpoint。

模型是共享資源

切模先進 draining、阻止新工作、等 lease 歸零才 unload；不會卸掉別人正在使用的模型。
