PLAIN-LANGUAGE MAP · 2026-08

FreePy 到底要往哪裡長？

這份是 ROADMAP.md 的翻譯機。它不是另一套規格，而是先幫你分清楚：現在已經能做什麼、正在補哪個可靠性缺口、後面那些 package 又各自負責什麼。

一句話：先把「一個 agent 做事」變得可檢查、可恢復，再慢慢加上資源、多人、記憶與 OS 隔離；不會反過來先堆一個很大的平台。

THE MAP

核心不是取代一切，而是把各層接好

Agent Machine

現在開始的協調核心：先統一檔案狀態與提交，再逐步加入 executor、排程與資源。它只定規則與資料，不自己變成模型供應商或沙箱。

各專職元件

實際跑模型、呼叫工具、留記憶、啟 worker、送訊息的地方。核心透過明確接口叫它們做事。

agentloop單一 bot 的 Round runner
llmkit模型 endpoint 與工具格式
runtimeOS worker／隔離
memorycontext 與資料來源
team / comm組織、授權與訊息

所以「Agent Machine」不是一隻比較聰明的 agent；它比較像交通規則加帳本。真正做事的 agentloop、模型與工具仍各守自己的工作。

WHERE WE ARE

本地 loop 已能跑；現在建立可恢復的檔案狀態

現有可用的底座

llmkit 能對 OpenAI-compatible 模型發請求並描述工具；agentloop 能讓單一 bot 做「問模型 → 跑工具 → 再問」；Handle 是同 process 的直接把手。

眼前的 Python 切片

先做 path、stable node id、immutable snapshot 與 root generation；下一個 PR 才做 durable journal/HEAD recovery，再加入 derived Git checkpoint。

MILESTONES

路線不是八件同時開工的事

現在 · PR 1–3

VFS contract、recovery、Git checkpoint

先以 deterministic operations 驗 path／generation，再做 crash recovery；刻意不接真模型、scheduler、FUSE 或 Janet。

底座已完成

Round control 與 Controller

safe boundary、逐步 advance() 與直接 Bot API 已可用；保持它只是本地抽象。

M2–M3 · 不會遺忘，也不輕信

持久控制、目標與驗證

資料可在重啟後留下；崩潰時知道哪件工具結果未知；模型說「完成了」仍必須有證據或驗證者判定。

M4–M5 · 能安全地跑，也記得住

身份、runtime、記憶

補身份與訊息，再做 Linux worker／sandbox；記憶要有來源、權限和 context 預算，不能把所有東西硬塞 prompt。

M6 · 多 agent 的資源關係

team hierarchy

先做成員、授權、分配與回報，最後才允許 spawn subordinate，避免一開始就得到無法控管的 agent 組織。

M7 · 讓狀態可被看見

Plan 9 projection

把已有的狀態投影成可讀的 namespace；寫入只能翻譯成既有操作，不能繞過規則直接改真實資料。

MINIMUM VOCABULARY

先只記這幾個詞就夠了

Round

一個 bot 為了完成一件事，從開始到停止的一整段工作。

Step

Round 裡的一次問模型與得到回覆；工具發生在兩個 Step 中間。

Handle

直接操作本地 Round 的把手；公開、可變、單純。

Controller

組合 Handle 的本地便利封裝，不是安全或耐久化控制平面。

safe boundary

剛好可以停下或交棒的位置；不會停在半套工具配對中間。

durable

不只放在記憶體：關掉程式、重啟後仍可知道做到哪裡。SQLite 是日後的候選資料庫。

WHY THIS ORDER

每一步都先排除一種昂貴的錯誤

  1. 先做純核心：先證明資源與事件規則正確，避免錯誤被真模型的隨機性掩蓋。
  2. 再做逐步 runner：先知道能在哪裡安全停下，才談得上排程、暫停或接手。
  3. 再做持久化：先有正確的狀態轉換，資料庫才是在保存規則，而不是保存一團混亂。
  4. 最後才擴大權限：多人、記憶、OS 工具都會放大失誤，所以要建立在前面可驗證的邊界上。

想看目前程式的實際契約，優先看 package README／docstring；想看未完成的細節，才看各 package 的 PLAN.md。本頁與 Roadmap 都是在說「先後順序」。
